# AgroValley - Proyecto Final

Entorno rural interactivo desarrollado en **Unity** con soporte para gráficos en **URP (Universal Render Pipeline)** y el nuevo **Input System**. El proyecto ambienta una granja tradicional con zonas de cultivo, elementos arquitectónicos, fauna animada y mecánicas básicas de exploración y entorno.

---

## Controles y Mecánicas

- **Movimiento:** Teclas `W`, `A`, `S`, `D` para desplazarse.
- **Cámara:** Movimiento con el ratón (tercera persona).
- **Salto / Carrera:** `Espacio` para saltar / `Shift Izquierdo` para esprintar.
- **Interacción con el entorno:**
  - **Puerta de la valla:** Apertura y cierre suave mediante detección de proximidad (*Trigger*).
  - **Mecánica acuática:** Zona de río navegable adaptada a la escala y altura del personaje.
  - **Fauna ambiental:** Animales distribuidos en el mapa con ciclos de animación en bucle (*idle*).
